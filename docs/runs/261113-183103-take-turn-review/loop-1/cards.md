# Kept cards, loop 1 (6 cards)

## L1#1: Let dispatch retry rejected CLI seats
When a CLI or API seat returns invalid output, ingest writes a retry prompt and prints `RUN council.py dispatch`. But cmd_dispatch skips every seat whose output file already exists unless --seat is passed, so the rejected file blocks its own retry: dispatch answers `nothing to dispatch`, ingest rejects the same file again, and the chair loops or guesses. All three cross-lab elders travel this path. Fix: dispatch re-runs any seat that has a retry prompt newer than its output, and the printed retry line names the seats. One unit test: invalid elder output, ingest, dispatch --dry-run must list that seat. No new concept; the two-command loop stays as it is.
Wins: R1, R5, R4 · Evidence: skills/council-loop/scripts/run.py: cmd_dispatch (`if o.exists() and not seat: continue`), spawn_lines (retry line prints plain `council.py dispatch`), _collect (writes .retry.md, leaves the bad .out.json). Found by reading the code; not executed. tests/test_run.py covers the retry prompt only for subagent seats.
ELI5: A broken answer from an outside model currently blocks asking again. Let the tool ask again.

## L1#2: Next resumes: spawn only missing seats
After a context reset the chair runs status, then next. Today next rewrites every prompt and prints SPAWN lines for all seats of the phase, including seats whose valid output is already on disk, so a reset mid-fan-out re-spawns up to seven agents at roughly 60k tokens each and overwrites good work. Fix: next validates existing outputs first and prints only the seats still missing or invalid, with a line such as `5 of 7 in`. It stores an attempt count per seat and prints the exact --force command at the second failure, so the `fails twice` rule no longer lives in chair memory. Status shows the same pending list.
Wins: R1, R3, R2 · Evidence: skills/council-loop/scripts/run.py: next_ideate, next_vote, next_rank, next_elders call spawn_lines with only=None; cmd_status ends `next: council.py next`; run['retries'] is one global counter. 60k per spawn is from the packet facts. Found by reading the code; not executed.
ELI5: After a restart, only redo the seats that have not answered, and let the tool count failures.

## L2#1: Derive card authors from provenance, not chair input
Self-vote exclusion in tally() trusts each card's authors list, and the chair types that list by hand twice: in pool.json at merge and in candidates.json at fuse. _check_cards only checks that authors is a non-empty list of expert seat ids; nothing reads the from or parents fields. A fused card built from L2 and L3 cards but labelled [L1] lets L2 and L3 rank their own work, unrecorded. Fix: ingest_merge requires every from ref to be a real kept-card ref and sets authors to those seats; ingest_fuse requires parents to be shortlisted pool ids and sets authors to the union of the parents' authors. One unit test covers both.
Wins: R2, R5 · Evidence: skills/council-loop/scripts/run.py: _check_cards (lines 974-983), ingest_merge, ingest_fuse (line 1084 copies parents unchecked); council.py tally() own-label exclusion (line 349). Read on paper; no exploit test run.
ELI5: The computer, not the referee, writes whose idea each card came from, so nobody can vote for their own.

## L2#2: Give each voter its own candidate order
blind() is seeded only by run, loop and phase, so every voter in a phase gets the identical packet, and the same card sits first on all seven ballots. LLM judges show measurable position bias (Zheng et al. 2023, MT-Bench), so a shared order adds the same tilt to every ballot and Borda sums it instead of cancelling it. Fix: keep one label-to-card mapping per phase, but have write_seat_prompts render each seat's copy in a rotated order (Latin square over seats), so each card leads about equally often. Labels, mapping and tally are unchanged; no model calls. Test: with seats at least equal to cards, every label leads some packet.
Wins: R2, R5, R1 · Evidence: skills/council-loop/scripts/run.py seed_for() and _vote_prompts() write one packet for all seats; council.py blind() emits cards in label order. Position bias: Zheng et al. 2023 'Judging LLM-as-a-Judge' (from memory, not re-checked this session).
ELI5: Everyone sees the cards in a different order, so being listed first stops giving a free boost.

## L3#1: Reject agents only for faults the run reads
Every rejected expert is a full respawn: about 60k tokens of host overhead plus the whole task again, and after two failures the chair must drop that voice, breaking the seven-lens rule. Three checks guard nothing downstream: ideas over 25 words (only counted; check_run already treats them as a warning), incomplete elder scores (stored, never read by cut or final), and ballots missing, repeating or misnaming a label (tally already ranks gaps neutrally). Make the first two warnings, repair ballots missing up to one in ten labels, and log each repair in run.json. Self-vote exclusion and blind labels stay untouched. Idea count, card shape and verdicts stay hard errors.
Wins: R1, R3, R5 · Evidence: run.py v_ideate, v_elder, v_ballot (lines 341-424), ingest_ideate 956-966, ingest_elders 1120; council.py check_run 459-464 and tally; tests/sim.py 'partial' mode is never used by test_run.py. Counted with a script: 7 of my own 11 first-draft idea lines exceeded 27 words (one model, small sample). Real rejection rates for other agents: unverified.
ELI5: Do not make an expert redo everything because one idea line ran long or a ballot skipped one name.

## L3#2: Remove two stalls found by running the kit
Running the kit in a scratch copy reproduced two stalls. First, when a CLI-run expert's output is rejected, ingest prints 'RUN council.py dispatch', but dispatch skips any agent whose output file exists and answers 'nothing to dispatch'; only --seat works. Fix: move the rejected file aside to a .rejected.json name when the retry prompt is written. Second, the identity-leak check flags ordinary cost phrases built on the word for a council place (five of five tried), so the chair must rewrite cards at merge. Narrow it to real ids: an L-number, RT, an E-letter or CTRL after that word; bare ids stay forbidden. Add one test for each.
Wins: R1, R2, R5 · Evidence: Reproduced in a /tmp copy: cmd_dispatch (run.py, 'if o.exists() and not seat: continue') printed 'nothing to dispatch' for a rejected codex agent; council.blind flagged 5 of 5 'seat call / seat cost / seat vote / seat fan-out' style phrases tried; council.py LEAK_RE. The codex and gemini live paths themselves: unverified.
ELI5: Two stuck buttons: a retry that does nothing, and a blind-check alarm that rings at ordinary words.
