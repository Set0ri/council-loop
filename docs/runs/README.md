# Published run records

Each folder here is the complete record of one real council run: the brief, every packet a seat
received, every answer, the ballots, the ledger, the final write-up and the retro.

These are copies made for publication. Two things were replaced, and nothing else:

- the paths of the machine the run was made on (written as `<repo>`);
- the name of the person who asked for the run (written as "the requester").

Because of that, `council audit` is not meant to be run on these folders: it compares the answers
with the hashes taken when they were accepted, and a replaced word changes a hash. The write-up of
what each run found is beside this folder: `../council-run-2026-11-13-self-review.md`.
