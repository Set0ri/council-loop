# Tutorials

> ELI5: learn by doing. Each page takes one thing from start to finish, with the commands to type
> and what the program really prints.

| # | Tutorial | Time | Needs |
| --- | --- | --- | --- |
| 1 | [Your first council](01-first-council.md): install, watch a whole council, read what it leaves behind | 5 minutes | Nothing. No model is called |
| 2 | [A real council in Claude Code](02-a-real-council.md): the plugin, the chair's five judgment points, what it costs | 30 minutes and up | Claude Code, and tokens |
| 3 | [Codex, Gemini CLI, Cursor and other agents](03-other-ai-tools.md): `AGENTS.md`, the MCP server, seats behind other tools | 15 minutes | One of those tools |
| 4 | [Locked tests and CI](04-locked-tests-and-ci.md): an answer key no agent can bend | 10 minutes | git |
| 5 | [The shared memory and Obsidian](05-shared-memory-and-obsidian.md): facts with sources, kept across runs | 10 minutes | Nothing (Obsidian is optional) |
| 6 | [Build on the API and the MCP server](06-build-on-the-api.md): drive a council from a program | 15 minutes | A shell; `jq` helps |

Every output block on these pages was printed by version 0.5.0. Paths are shortened to
`<project>`; run ids carry the date and time of the run, so yours will differ.

After the tutorials: [`how-to.md`](../../skills/council-loop/reference/how-to.md) for recommended
practice and ten worked examples, [`commands.md`](../../skills/council-loop/reference/commands.md)
to look something up, [`operations.md`](../operations.md) when something goes wrong.
